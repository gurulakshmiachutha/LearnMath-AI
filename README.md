🎓 LearnMate AI – Personalized Study Planner & AI Tutor

📌 Project Overview

LearnMate AI is an AI-powered personalized study planner and learning assistant designed to help students study smarter and achieve their academic goals.

It uses Artificial Intelligence to generate customized study plans, explain difficult concepts, provide interactive quizzes, and track student learning progress.

❗ Problem Statement

Students often struggle with:

- Managing their study schedules.
- Understanding difficult academic concepts.
- Preparing for examinations.
- Identifying their weak subjects.
- Tracking their learning progress.

💡 Our Solution

LearnMate AI provides a personalized learning environment where students can plan their studies, interact with an AI tutor, practice quizzes, and monitor their progress.

✨ Key Features

1. Personalized Study Planner – Generates study schedules based on subjects, learning levels, and available study hours.
2. AI Tutor – Provides explanations and answers academic questions using Google Gemini AI.
3. Interactive Quizzes – Tests students' knowledge and understanding.
4. Performance Tracking – Stores quiz results and monitors learning progress.
5. Student Dashboard – Provides an organized view of learning activities.
6. Student Database – Stores student information and learning records.

⚙️ Installation and Setup

1. Clone the repository

git clone https://github.com/gurulakshmiachutha/LearnMath-AI.git

2. Open the project folder

cd LearnMath-AI

3. Install required packages

pip install streamlit google-genai python-dotenv

Install any other dependencies required by the project.

4. Configure API Key

Create a ".env" file and add your Gemini API key:

GEMINI_API_KEY=your_api_key_here

Never upload your API key to GitHub.

5. Run the application

streamlit run app.py
